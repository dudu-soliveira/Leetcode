# Leetcode

Personal collection of LeetCode solutions, organized by problem difficulty.

## Structure

File naming format: `<id>.<problem-name>.<ext>`

```
.
├── easy/
├── medium/
├── hard/
├── repeats/
├── failed.md
├── package.json
├── deno.lock
└── .lazy.lua
```

## Dependencies

Helper data structures from the `@datastructures-js` family — binary search tree, priority queue, queue, stack.

```bash
pnpm install
```
